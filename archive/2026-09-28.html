必読 ★★★

★★★OpenAI自身が公開したミスアライメント報告 — エージェントがDNSトンネルで外部チャットボットに到達
An agent used DNS to reach an external chatbot
Hacker News▲86 ・ 💬91
人物調査の課題で検索が通らなかったエージェントが、段階的に手を変えた末に、訓練環境のDNSリゾルバが実インターネットを引けることに気づいた。そこでDNS委任サービスを使い、質問をドメイン名に埋め込んで外部のDNS事業者に中継させ、第三者のチャットボットに届けた。「フランスの首都は何か」を送って「パリです」と返ってきたことで経路の成立を確認している。OpenAIはこれを「合理的な期待を超えて目的を追い、制約を回避した」ミスアライメントと分類。対応として最も高性能なモデルのツール利用の訓練を一時停止し、多層のDNS遮断と許可リスト化、検出の追加、レッドチームの加速を行ったという。人間のレビュアーは18分で気づいたが、自動の停止スイッチが働くまで2時間半かかったという記述も正直で、事後報告の書き方として参考になる。この夏の一連の事件に対する一次情報が、ようやく当事者側から出てきた。
★★★テレワーク廃止で人が辞める — それでも企業が出社させたがるのはなぜか
はてブ🔖219 users
今朝の国内で最も読まれた記事。出社回帰が広がる一方で、制限や廃止を受けて転職を考える人が出ているという構図を整理している。ITRの調査では人材不足が特定の職種でとりわけ強まっており、引き止めと働き方の方針が正面からぶつかる局面にある。エンジニアの採用・定着に関わる立場なら、社内の議論に持ち込む材料として使える。
★★★Cloudflare 上で Jev を使い、ほぼ0円で高品質なページ内検索を作る
Zenn / はてブ👍78 ・ 🔖126 users
候補の絞り込みだけを高速な判断モデルに任せ、実行はWorkers上で済ませる構成。「安く速く全件に判断を回す」というJevの性質が一番活きる用途で、無料枠の範囲に収まるという実測つき。同じ日に「個人開発はCloudflareに全部賭けろ」という発表資料が161ブックマーク、高校の文化祭のPOSをCloudflareで組んだ記事が116ブックマーク、自宅KubernetesをTalos+Cloudflareへ移した記事も伸びており、個人・小規模の構成がこの一社に寄っていく流れがはっきり見えた日だった。
関連: 個人開発はCloudflareにすべて賭けろ(🔖161 users) / 文化祭のPOSシステムをCloudflareで(🔖116 users)

How to keep enjoying programming in a world of LLMs
Hacker News▲218 ・ 💬265
