★★★良品計画、クレカ番号の全桁 約109万件が漏えいのおそれ
良品計画 クレカ番号の全桁 約109万件が漏えいのおそれ
はてなブックマーク
無印良品を展開する良品計画は、不正アクセスを受けてクレジットカード番号の全桁、およそ109万件が漏えいしたおそれがあると発表した。10月31日号で扱った「最大2726万件」の件ではカード情報は含まれないとしていたが、その後の調査でカード番号の漏えいが判明した形になる。被害の範囲が広がったことになり、続報として扱う。
関連: 10/31号: 2726万件の情報流出
★★★PHP2Shellが示す「AIが40年分の技術的負債を払わせる」現実
The PHP2Shell Vulnerability Heralds Cybersecurity Hell
Hacker News
IEEE Spectrumが、10月下旬に明らかになったPHP2Shellを、AI時代のセキュリティの転換点として論じている。何十年も前からあるコードの脆弱性が、AIによる発見と悪用の高速化で一気に表に出るようになり、組織は「40年分の技術的負債」を払わされる立場になったという整理。個別の製品の話ではなく、古いコードベースを抱えること自体のコストが上がったという指摘。
関連: 10/30号: PHP2Shellで25台をroot化

開発・エンジニアリング ★★

★★★Nvidia RTX SparkのLinux、暗号化ファームで推論が大幅に減速
Linux on the Nvidia RTX Spark Laptop: What Actually Works
Hacker News
MSI Prestige RTX SparkでLinuxをデュアルブートすると、GPUのクロックがWindowsの約2.2GHzに対し約780MHzまで落ちる。電力管理のファームウェアが暗号化されており、Windowsのドライバしか復号できないためだという。GPT-OSS-120Bの計測ではWindowsが65.4トークン/秒、WSLが65.1、DGX Sparkが61に対し、ネイティブLinuxは13.9トークン/秒だった。
★★★Go 1.27でencoding/json/v2が正式に利用可能に
A new Go API for JSON
Hacker News
Go 1.27でencoding/json/v2とencoding/json/jsontextが安定版として利用可能になった。15年以上使われてきたencoding/jsonの問題点を整理し、新しいAPIの使い方を紹介している。
★★★OpenCode＋Docker＋GitHub Actionsで全自動AIペネトレーションテスト
OpenCode+Docker+GitHub Actionsで全自動AIペネトレーションテストはじめました
はてなブックマーク
Zennチームが、AIによるセキュリティチェックをPull Requestのたびに回す仕組みを作った。OpenCodeをDockerコンテナで動かし、GitHub Actionsから自動でペネトレーションテストを実行する構成を説明している。
★★★ECS＋RDSからLambda＋Aurora DSQLへ、インフラ費用がほぼゼロに
ECS + RDS → Lambda + Aurora DSQL の移行で社内アプリのインフラ費用がほぼゼロになった話
Zenn
社内アプリの構成をECS＋RDSからLambda＋Aurora DSQLへ移行し、インフラ費用がほぼゼロになったという事例。移行の判断と、構成変更で何が変わったかを説明している。
★★★ドコモ社長、5G基地局が他社より少ない理由を説明
ドコモ社長、5G基地局がKDDIやソフトバンクより少ない理由を説明
はてなブックマーク
NTTドコモの前田義晃社長は11月4日の決算説明会で、5G基地局数がKDDIやソフトバンクより少ない理由を説明した。通信容量を確保できるサブ6帯域の扱いなど、周波数の特性に応じた投資判断があるという説明になっている。
